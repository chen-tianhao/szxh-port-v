# 中国港口 / 内河航道数据可得性

做苏州港或任何中国内河港口研究前先看这张表：**统计与航道空间数据免费可靠，
船舶级 AIS 官方渠道拿不到。** 任何默认"能下 AIS"的研究设计都要先改。

## 分层清单

| 层 | 最好用的免费源 | 说明 |
|---|---|---|
| 港口吞吐量 | 交通运输部官网「统计数据」分港口月度表；年度《交通运输行业发展统计公报》 | 唯一官方分港口序列；到港口级，不到泊位级 |
| 港区细分 | 各市政府网站（太仓/张家港/常熟式发布） | 比部级更快更细，能到港区 |
| 航道空间 | 长江e+ / 长江电子航道图（干线全覆、支流接入）；江苏省内河电子航道图 | 是**服务产品**，不是可下载数据集 |
| 全国基线 | 统计公报里程数；天地图 1:100 万水系 shp | 1:5 万需测绘审批 |
| 船闸通过量 | 省级交通部门船闸通过量发布（艘次/总吨/货运吨） | 做通过能力与拥堵，常比 AIS 更好用 |
| 运价 | 长江航运指数月度 PDF（集装箱 + 干散货） | 周/季/年序列，武汉航交所编制 |
| 船舶轨迹 | 官方渠道不可得，见下 | |

## AIS 获取现实

- 海事局对公众咨询的答复是明确的：船舶 AIS 数据**只提供给政府单位，不对公众开放**。
  交通行业单位走部数据共享平台，其他部委/省政府走国家共享交换平台与政务服务平台。
- 公众 AIS 门户（ais.msa.gov.cn）是**网页查询工具**：单船或组合查询、实时位置航速、
  部分历史航迹 —— 没有 API、没有批量导出、没有归档。只能做抽查和单船跟踪。
- **不要引用"约 3.5 万艘"当样本量。** 那是门户上线新闻里的日均可见船数估算，从未更新，
  且是沿海与内河合计。对比统计公报的全国水上运输船舶约 10 万艘，说明覆盖是部分的；
  单一河段某一时刻可见船数远低于此。
- 现实进攻顺序：机构/高校合作 → 商业 AIS 供应商 → 公开小样本研究数据集
  （通常单船数天或单港数月）→ 官方门户仅做校验。
- 用浏览器脚本重放门户内部请求技术上可行，但属于绕过接口授权：不稳定，且论文里
  不好交代许可。作为兜底，不做主数据源，且要告知用户这个取舍。

## 境外开放历史 AIS（对比材料）

美国 MarineCadastre（2015 起按天归档，另有月度 GeoParquet）、丹麦海事局（单日 CSV，
最高 2 GB/天）、挪威 Kystverket HAIS（NLOD 免费，Parquet，需登录，排除 15 m 以下渔船
与 45 m 以下游艇，扩展权限发邮件申请）、澳大利亚 AMSA（按月，滞后约 3 个月，不含船舶
标识）、韩国（矩形海域，MMSI 脱敏）。全球免费流：aisstream.io、AISHub；
IMF PortWatch 只有汇总、无轨迹。解释"中国官方口径是政策选择而非技术限制"时用得上。

## 坑

- **混用港口口径与"内河港"口径。** 港口总吞吐含其内河/湖区港区；单独发布的"内河港"
  数字是另一个统计对象，相加前必须写清口径。
- **运营主体合并会打断时间序列。** 两个码头合并为一家运营公司后，归属该码头的吞吐量
  会跳变。要问合并日期，并在数据说明里标注（鑫海 + 万方为 2024 年 8 月）。
- **聚合型港口网站布局陈旧。** 泊位、水深、门机数、权属要读港口集团自己的站和市政府
  发布；港口黄页类目录常滞后数年且把主港区写错。
- **别假设交通类开放数据平台有 AIS。** 台湾 TDX 只有港口、船舶规格、班表等，
  没有原始船位；没有官方端点就不要写"有"。
- **照抄"未核实"标记。** 汇总里出现"是否免费未核实"或引用第三方 SDK 时，
  先去运营方官网核实 —— 不少这类标记最后被证明是错的，一行错就毁整张表。
- **把历史 AIS 页面当成可批量下载。** 先分清是查询界面还是文件/API 端点；
  若干"历史 AIS"服务是按单查询下载，不是开放档案。

## 本项目的取数结论

数字孪生的数据层先接甲方 TOS / PORTS（泊位占用、堆场货位、在港船舶），
这三样内部系统里有；AIS 只做小样本微观校验。见根目录 README 的阶段 3。
